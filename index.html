Chapter 1

Welcome

Hi! I'm Hana. I'm a business owner, not a programmer.

Like many business owners, I'm always juggling responsibilities and looking for practical ways to make running a business simpler. That's what led me to experiment with Claude Code.

I discovered I could build my own AI-assisted video editing workflow without knowing how to code. I could give AI instructions, set my editing preferences, and use them to turn raw footage into edited videos.

This playbook assumes you're starting from absolutely zero. You don't need to know what Git, Node.js, FFmpeg, Python or an API key is. You don't even need Claude installed yet. We'll start with the basics and work our way to your first edited video.

Chapter 2

What exactly are we building?

An AI-assisted video editing workflow, powered by Claude Code and an open-source editing project. Instead of doing every editing task by hand, you describe what you want in everyday language, and Claude uses the editing tools on your computer to do it.

Traditional editingAI-assisted editing
Manually cut clipsAsk AI to find and remove pauses
Manually create captionsTranscription generates captions for you
Adjust each edit yourselfDescribe your preferred editing style
Repeat the same tasks every timeReuse prompts and saved settings
Learn complex editing softwareGive instructions through Claude Code

What your AI editor can help with

  • Removing pauses and mistakes, and cutting unneeded footage
  • Generating captions
  • Creating short-form videos and applying basic visual styles
  • Exporting MP4 videos and making revisions
  • Reusing your editing preferences on every video

Always review before you publish. AI-assisted editing won't always be perfect. This playbook isn't meant to replace professional video editors. It's one more tool for your creative workflow.

Meet your tools

"What is Git? What's Node.js? Why do I need FFmpeg?" Here's each one, explained simply.

Claude CodeYour AI technical assistant

Works with files on your computer and runs commands you approve.

GitYour project downloader

Brings the editor from GitHub onto your computer.

Node.js + npmThe software engine

Runs the editor's JavaScript tools and setup script.

FFmpegThe video engine

Cuts, combines, converts and exports video and audio.

PythonOnly for local transcription

Needed if you choose faster-whisper.

GroqOptional transcription

Turns the speech in your videos into text, online.

Tool 1 · Claude Code your AI technical assistant

  1. Go to the official Claude download page and download Claude Desktop.
  2. Open the downloaded file and follow the installation instructions.
  3. Open Claude Desktop and sign in (or create an account).
  4. Open the Code section and choose your own computer as the environment.

You'll know it's working when you can start a conversation in Claude Code. If Code isn't available, check your plan's access.

Tool 2 · Git your project downloader

Download it from the official Git page. On Windows, the recommended installer settings are fine. On a Mac, Git may already be installed. Then let Claude check:

Please check whether Git is installed on my computer.

If installed, show me its version.

If missing, explain how to install it.

Do not install anything without asking me.

Tool 3 · Node.js the software engine

Download the LTS version from the official Node.js page. free247editor needs version 22 or newer. npm, the tool that installs JavaScript add-ons, comes with it.

Please check whether Node.js and npm are installed correctly.

Show me their versions.

Explain whether they're compatible with my AI video editing project
(it needs Node.js 22 or newer).

Tool 4 · FFmpeg the video engine

Downloads are on the official FFmpeg page, but installing it differs between Windows and Mac. Let Claude guide you:

I'm a complete beginner.

Please check whether FFmpeg is installed.

If it isn't:
1. Identify my operating system.
2. Explain the safest installation method.
3. Use official or trusted sources.
4. Ask for my permission before installing.
5. Guide me through each step.
6. Verify that FFmpeg works.

Do not change unrelated files.

Tool 5 · Python only for local transcription

Available from the official Python page. Don't install it yet. You only need it if you pick faster-whisper in Chapter 9.

Tool 6 · Groq optional transcription

Groq turns the speech in your videos into text, which powers captions. It uses an API key: a private access code, like a password that lets software talk to an online service.

  1. Go to the Groq Console and create an account.
  2. Open API Keys and click Create API Key.
  3. Name it My AI Video Editor, copy it, and store it somewhere private.

Never share your API key publicly, in chat, or in screenshots.

Chapter 5

Prepare your computer

  1. Create your workspace. In your Documents folder, create a folder named AI Video Editor.
  2. Record a test video. 30–60 seconds on your phone or webcam. Include a few pauses or restarts on purpose.
  3. Open Claude Code in the local environment. We want the editor on your own computer, not in a temporary cloud workspace.

Try saying: "Hi everyone! Today I'm testing my AI video editor. I want to see if it can remove unnecessary pauses, create captions, and help me turn this recording into a finished video."

Chapter 8

Install your AI video editor

In free247editor, setup starts with one word: start.

  1. Open Claude Code inside the free247editor folder.
  2. Type start. Claude follows the project's CLAUDE.md, runs the one-time setup script (node setup.mjs), installs any missing tools with your approval, renders a test video and asks about your style.
  3. Read each permission request before you approve it.

What does node setup.mjs mean? node runs a JavaScript program, and setup.mjs is the setup program. It's safe to run again. Want every step explained first? Paste this instead of start:

I'm ready to install my AI video editor.
Please read the project's official setup instructions in CLAUDE.md.

Before running node setup.mjs, explain what it does.

Please:
1. Check all required dependencies.
2. Explain any missing components.
3. Ask permission before installing.
4. Follow the official setup instructions.
5. Stop if an error occurs.
6. Explain errors in simple language.
7. Verify whether setup completed.

Do not delete unrelated files.
Guide me one step at a time.
Please verify that my AI video editor was installed successfully. Tell me:

1. What was installed.
2. Whether anything is missing.
3. Whether there were errors.

2. Read its official configuration instructions.

4. Show me exactly where the API key belongs.
5. Help me open the file safely.
6. Let me paste the key myself.
7. Never ask me to reveal the key in chat.
8. Never print or display the key.
9. Make sure the key is excluded from Git commits.
10. Help me test transcription.

Guide me one step at a time.

My goal: a clean, professional Instagram Reel.

Instructions:
1. Inspect the footage.
2. Remove unnecessary pauses.
3. Remove obvious mistakes.
4. Keep the pacing natural.
5. Add readable captions.

7. Avoid excessive transitions.

Ask one question at a time.

- Explain any limitations.
- Save my preferences in my style file.
- Show me how they'll be reused.

Do not overwrite existing settings without my approval.

Chapter 15

Request revisions

Your first edit doesn't have to be perfect. Just say what to change, in English, Tagalog or Taglish:

"Make the captions smaller.""Remove the background music.""Cut the intro shorter.""Gawing mas natural yung pacing."

Want a change on every future video? Tell Claude to save it as a rule, and it goes into my-rules.md.

Please revise my latest edited video.

Here are the changes I want:
[INSERT YOUR CHANGES]

Keep everything else the same where possible.

Please:
1. Explain what you'll change.
2. Confirm which files will be affected.
3. Save the revision as a new version.
4. Do not overwrite my original export.
5. Tell me where the updated video is.
